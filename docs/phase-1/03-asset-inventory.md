## Typography (sampled font-families)

| Role | Current font | Notes |
|------|--------------|-------|
| Wordmark/logo | Serif (Times-like) | Decorative; keep as brand mark only |
| Display / headings | `Madefor-Display-Bold` (Wix Madefor) | Geometric sans |
| Body | `Madefor-Text`, `Montserrat`, Helvetica/Arial fallbacks | Mixed — inconsistent |

- **Observation:** type usage is inconsistent (Madefor + Montserrat + Helvetica +
  Times all present). The new design system should define a tight, intentional pair
  (e.g. one expressive display + one clean UI/body sans) — see Phase 3.
