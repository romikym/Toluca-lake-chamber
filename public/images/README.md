# Site photography

Drop real photos here to replace the green-gradient placeholders. The site
references these exact paths and falls back to a tasteful gradient if a file
is missing — so nothing breaks before you add them.

## Hero
- `hero-toluca-lake.jpg` — the large scenic hero image (lake / hills / village).
  Recommended: landscape, ~1600×1200 or larger, optimized JPG/WebP under ~400 KB.

## Event covers
- `events/<event-slug>.jpg` — one image per event, shown on the home + events cards.
  The slug is the event's URL segment (e.g. `events/community-cleanup-fall.jpg`).
  Recommended: landscape 4:3, ~800×600.

Tips:
- Keep files web-optimized (compress before adding).
- JPG or WebP both work. Match the filename exactly (case-sensitive on the server).
